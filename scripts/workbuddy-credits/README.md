# WorkBuddy 积分 · Scripting

适用于 WorkBuddy 国内个人账号。独立项目，不读取其他 Scripting 脚本的授权，也不依赖 Surge 或自建服务器。

## 使用方式

1. 直接打开原来的「WorkBuddy 积分」，无需卸载重装。旧账号继续使用原钥匙串记录和缓存，并显示为 `WB1`。
2. 在「账号列表 → 添加手机号」打开隔离的 WorkBuddy 官网页面，选择手机号登录，完成验证码验证和授权后关掉网页。如果未自动完成，点「检查授权」。如果隔离页打不开，可以手动点「用 Safari 打开」并在官网选择另一个手机号。已有账号不会因为新增被覆盖；同账号重复授权只更新该条记录。
3. 点账号查看总可用积分、签到剩余、今日已领/可领、连续签到与有效积分包；可以独立刷新、重新授权或移除。移除只清除此脚本内该账号的本机授权和缓存。
4. 所有桌面尺寸都使用同一份已添加账号列表，无需填写参数；原先的单号绑定不再生效。小号或中号放得下就全部显示，放不下只提示切换为大号，不截去最后几个账号。大号同时显示所有已添加账号（最多 20 个），账号多时自动改成双列。点任意桌面卡片都打开账号列表，没有「桌面默认」设置。
5. 可点「预览大号 · 全部账号」检查。若桌面还是旧样式或部分账号没有余额，进账号列表点「刷新全部」。大号后台分批查询，尚未取得数据的账号也会列出，实际刷新时机由 iOS 决定。

## 读数说明

- **总可用积分**：WorkBuddy 资源余额接口返回的当前有效 `credits` 资源的剩余积分合计；包含已计入的签到积分，不另加一次。「总可用」不是套餐历史总额度。
- **签到余额**：仅汇总可明确识别为签到奖励的积分包。数据不足时显示「无法确认」（紧凑布局显示「未知」），并非 0 或未领取。
- **今日签到**：来自签到状态接口。「签到已领」和「签到可领」都指当天奖励，不是签到余额。活动未开放和请求失败保留各自状态；脚本不自动领取。
- 断网可显示最近一次有效余额并标记缓存时间；不会把昨天的签到状态当今天的。退出账号会清除本脚本缓存与授权，下次需重新授权。

手机号和验证码只在官网填写。会话凭据保存在该脚本的本机钥匙串，不同步 iCloud 也不在日志中输出；脚本页最多显示手机号尾号。凭据只发往 WorkBuddy 的 HTTPS 接口。不要把验证码或登录链接转发给别人。

## 验证范围

已匿名验证官网授权入口，按 Scripting 文档做了静态类型检查，并以模拟响应验证状态、续期与余额解析。首次真实授权、实际返回的签到积分包字段以及 iOS 主屏幕渲染尚需在设备上验证。
