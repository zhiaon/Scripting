# Scripting

iOS [Scripting](https://scriptingapp.github.io/) 的脚本与小组件源码。

## TokenHarbor

TokenHarbor 七天额度小组件：显示已用/剩余占比、重置时间与本地真实用量趋势。

- 源码目录：`scripts/tokenharbor/`
- 远程导入地址：

```text
https://github.com/zhiaon/Scripting/tree/main/scripts/tokenharbor
```

在 Scripting 的脚本设置里填上面的地址即可作为远程来源，跟随 `main` 更新，不需要下载 ZIP。
