# Scripting

用于保存 iOS [Scripting](https://scriptingapp.github.io/) 脚本和小组件的仓库。

## 说明

仓库只收录脚本源码与说明，不上传任何账户数据：手机号、授权凭据、验证码、余额缓存与真机截图都不随项目分发。使用前请在你的设备上自行登录、配置自己的 Key。

## 导入

脚本目录需包含 `script.json` 与入口文件。导入方式：

- Scripting 内「设置 → 从 URL 导入」，填入该脚本目录的 GitHub 链接；
- 或直接下载仓库内的源码目录，复制到 Scripting 的 `scripts/` 下。
