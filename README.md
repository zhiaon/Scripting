# Scripting

用于保存 iOS [Scripting](https://scriptingapp.github.io/) 脚本和小组件的仓库。

| 项目 | 版本 | 作者 | 源码 | 导入包 |
| --- | --- | --- | --- | --- |
| WorkBuddy 积分 | 1.2.2 | 许舟 | [脚本目录](scripts/workbuddy-credits/) | [下载 ZIP](dist/WorkBuddy-Credits-1.2.2.zip) |

**WorkBuddy 积分**支持多个手机号分别在官网授权，在主屏幕查看账号积分与签到状态，只查询，不自动签到。所有账号独立展示，小号或中号放不下时请使用大号。

首次安装：下载表格中的 ZIP，在 iPhone 上通过 Scripting 导入，再在系统主屏幕添加 Scripting 小组件并选择「WorkBuddy 积分」。已有本机脚本若不需要更新，无须重装。

仓库和 ZIP 仅包含脚本源码、元数据和说明。手机号及其尾号、账号授权、验证码、缓存和真机截图均不随项目分发。请在自己的设备上登录；不要将运行数据提交到仓库。
